22. اختبارات القبول
==================================================

TEST A:
إضافة CNAS كOrganisme
→ تظهر في القائمة.

TEST B:
إضافة Police لمريض
→ تظهر داخل Patient Detail.

TEST C:
Police منتهية
→ لا يمكن استعمالها.

TEST D:
Facture 10000 DZD وتغطية 80%
→ Part organisme = 8000
→ Part patient = 2000.

TEST E:
Plafond المتبقي 5000 فقط
→ Organisme share لا تتجاوز 5000.

TEST F:
Claim جزئية
→ كل Item له amountApproved مختلف.

TEST G:
إضافة Claim إلى Bordereau
→ لا يمكن إضافتها مرة ثانية.

TEST H:
تسجيل Paiement organisme جزئي
→ Claim = partially_paid.

TEST I:
تسجيل كامل المبلغ
→ Claim = paid.

TEST J:
رفض Claim
→ السبب إجباري.

TEST K:
User بدون insurance.claims.approve
→ HTTP 403.

TEST L:
Dashboard KPIs صحيحة.

TEST M:
PDF Bordereau يعمل.

TEST N:
Patient Detail يعرض Police وClaims.

TEST O:
0 TypeScript Errors.
0 Runtime SQL Errors.
0 White Screens.
