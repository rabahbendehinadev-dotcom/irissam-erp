ابدأ الآن Task عاجلة: Responsive كامل + PWA Installation لتطبيق IRISSAM HOSPITAL ERP.

مهم جدًا:
- لا تضف أي Module جديد.
- لا تغيّر منطق الـBackend.
- لا تغيّر قاعدة البيانات.
- لا تغيّر الهوية البصرية أو الألوان الرئيسية.
- لا تحذف أي Feature.
- أصلح فقط Responsive / Mobile UX / Tablet UX / PWA.
- راجع جميع الصفحات، وليس Dashboard فقط.
- الهدف أن يكون المشروع صالحًا للعرض غدًا على iPhone وAndroid وTablet وDesktop.

==================================================
1. المشكلة الحالية
==================================================

على الهاتف:
- الـSidebar تبقى مفتوحة وتأخذ نصف الشاشة.
- محتوى Dashboard يخرج خلفها.
- Cards وCharts تتداخل فوق بعضها.
- النصوص والجداول غير مقروءة.
- Topbar غير متكيفة.
- الصفحة ليست قابلة للاستعمال عمليًا.

اعتبر Screenshot الحالية مرجعًا للمشكلة.

3. Sidebar Mobile
==================================================

على Mobile وTablet:

- الـSidebar تكون مغلقة افتراضيًا.
- تفتح كـDrawer فوق المحتوى.
- Overlay داكن خلفها.
- زر Hamburger واضح في Topbar.
- الضغط خارجها يغلقها.
- الضغط على أي Route يغلقها تلقائيًا.
- تمنع Scroll الخلفية وهي مفتوحة.
- عرضها:
  - Mobile: min(85vw, 320px)
  - Tablet: 300px
- لا يبقى أي جزء من المحتوى مزاحًا لليمين.
- Desktop فقط تبقى Sidebar ثابتة.

==================================================
5. Dashboard Responsive
==================================================

كل Dashboard يجب أن يعاد ترتيبه:

Mobile:
- Cards عمود واحد.
- كل Card بعرض 100%.
- Charts واحد تحت الآخر.
- لا يوجد أي overlap.
- ارتفاع charts مناسب 240–300px.
- legends تحت chart وليس فوقه.
- tables تتحول إلى cards أو scroll أفقي مضبوط.
- padding أفقي 12–16px.

Tablet:
- Cards عمودين.
- Charts عمود واحد أو عمودين حسب العرض.
- لا يوجد نص مقطوع.

Desktop:
- حافظ على الشكل الحالي.

ممنوع:
- position absolute في layout الرئيسي.
- widths ثابتة كبيرة.
- min-width تمنع التصغير.
- overflow مخفي يخفي المحتوى.

10. Install App — Android وDesktop
==================================================

أنشئ Install App Manager مشترك.

على Android وDesktop:
- استمع إلى beforeinstallprompt.
- خزّن الـevent.
- أظهر زر:
  "Installer l’application"
- الزر يظهر في:
  - Topbar
  - User menu
  - Settings
  - Login page بشكل صغير وغير مزعج
- عند الضغط:
  - prompt()
  - تتبع userChoice
  - اخفِ الزر بعد install
- استمع إلى appinstalled.
- لا يظهر الزر إذا التطبيق مثبت بالفعل.
- لا يظهر داخل standalone mode.

على Desktop:
- أظهر Install App في أعلى Topbar قرب notifications أو داخل User Menu.
- يكون واضحًا لكن غير مزعج.

11. Install App — iPhone / iPad
==================================================

Safari iOS لا يدعم beforeinstallprompt.

لذلك:
- اكتشف iOS Safari.
- إذا ليس في standalone:
  - أظهر banner أو bottom sheet:
    "Installer IRISSAM ERP"
  - اشرح بصريًا:
    1. اضغط زر مشاركة Safari
    2. اختر "Sur l’écran d’accueil"
    3. اضغط "Ajouter"
- أضف زر "Compris".
- لا يظهر كل مرة:
  - خزّن dismissedAt في localStorage لمدة 7 أيام.
- أظهر التعليمات أيضًا داخل Settings > Installer l’application.

مهم:
- لا تقل إن iPhone يثبت تلقائيًا.
- أعطِ تعليمات Add to Home Screen الصحيحة.
- بعد التثبيت يفتح التطبيق standalone بدون Safari chrome.

==================================================
12. Offline Shell
==================================================

فعّل Offline Shell آمن:

- cache للـassets الثابتة فقط.
- لا cache للبيانات الطبية الحساسة بشكل عشوائي.
- API network-first.
- عند انقطاع الإنترنت:
  - اعرض Offline Banner.
  - لا تعرض بيانات قديمة دون توضيح.
  - لا تسمح بإرسال عمليات حساسة إذا لم يكن عندك queue موثوقة.
- لا تبدأ Offline Editing كامل الآن.

==================================================

- لا 404.
- back button يعمل.
- لا redirect loop.
- لا loading loop.

15. Performance Mobile
==================================================

- Lazy load للصفحات الثقيلة.
- لا ترسم جميع Charts دفعة واحدة إذا خارج viewport.
- ResponsiveContainer لكل Recharts.
- debounce للبحث.
- تقليل إعادة render.
- Skeleton مناسب.
- لا layout shift كبير.
- الصور والـicons محسنة.
