درك نبدأو بـ Super Administration / Centre de contrôle du système. هذا هو الموديول اللي يخلّيك تراقب السيرفر، قاعدة البيانات، الجلسات، النسخ الاحتياطية، الأخطاء والأمان من مكان واحد.

انسخ هذا البرومبت وابعثه لـ Replit:

ابدأ الآن تطوير Module كامل خاص بـ:
SUPER ADMINISTRATION / SYSTEM CONTROL CENTER
داخل نظام IRISSAM HOSPITAL ERP.
مهم جدًا:
- لا تغيّر التصميم العام للنظام.
- لا تبدأ أي Module آخر.
- استعمل PostgreSQL الحقيقي والـAPI الحقيقي.
- ممنوع Mock Data في Production.
- هذا الموديول متاح فقط لـ:
  - super_admin
  - system_administrator
  - مستخدمين عندهم Permissions صريحة.
- لا تعرض Secrets أو Passwords أو Tokens كاملة داخل الواجهة.
- جميع العمليات الحساسة تحتاج Confirmation واضحة.
- العمليات الخطيرة تحتاج إعادة إدخال كلمة المرور أو Step-up Authentication.
- دعم Français / العربية RTL / English.
- Responsive كامل على Desktop / Tablet / Mobile / PWA.
- جميع العمليات تسجل في Audit.
- TypeScript = 0 errors.
- Runtime SQL = 0 errors.
- 0 White Screens.

7. Restore Safety
==================================================
Restore عملية حساسة جدًا.
المطلوب:
- ممنوع Restore مباشر على Production بدون:
  1. إعادة إدخال كلمة المرور.
  2. Confirmation Phrase.
  3. Backup حديث.
  4. Maintenance Mode.
  5. Permission system.restore.
- إنشاء Restore Plan.
- Dry-run Validation.
- Check schema compatibility.
- تسجيل كل خطوة في Audit.
- منع Restore إذا يوجد Users نشطون إلا بصلاحية استثنائية.
لا تنفذ Restore فعليًا تلقائيًا في هذه المرحلة إذا البيئة لا تسمح؛ حضّر Workflow وValidation وواجهة إدارة آمنة.
