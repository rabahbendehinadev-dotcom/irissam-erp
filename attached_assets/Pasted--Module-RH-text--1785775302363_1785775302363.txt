26. اختبارات القبول
==================================================

TEST A:
إنشاء موظف مع عقد وAffectation
→ جميع السجلات تنشأ داخل Transaction.

TEST B:
Matricule مكرر
→ HTTP 409.

TEST C:
عقد منتهي
→ Alert تظهر.

TEST D:
إنشاء Shiftين متداخلين لنفس الموظف
→ HTTP 409.

TEST E:
Check-in متأخر
→ lateMinutes محسوبة.

TEST F:
Check-out
→ totalWorkedMinutes محسوبة.

TEST G:
طلب عطلة أكبر من الرصيد
→ مرفوض.

TEST H:
Manager يوافق ثم RH توافق
→ الرصيد يتحدث وPlanning يتحدث.

TEST I:
غياب غير مبرر
→ يظهر في Dashboard وتنبيه.

TEST J:
Badge Event
→ Attendance يتحدث.

TEST K:
Manager لا يرى موظفين خارج فريقه.

TEST L:
Employee لا يعدل بيانات موظف آخر.

TEST M:
Dashboard KPIs صحيحة.

TEST N:
Mobile Responsive يعمل.

TEST O:
0 TypeScript Errors.
0 Runtime SQL Errors.
0 White Screens.
