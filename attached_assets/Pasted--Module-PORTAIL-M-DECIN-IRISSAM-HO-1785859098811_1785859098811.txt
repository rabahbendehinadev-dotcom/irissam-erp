ابدأ الآن تطوير Module مستقل وكامل خاص بـ:

PORTAIL MÉDECIN — بوابة الطبيب

داخل نظام IRISSAM HOSPITAL ERP.

مهم جدًا:

- لا تغيّر تصميم الـERP الإداري الحالي.
- أنشئ واجهة منفصلة ومبسطة للطبيب.
- استعمل PostgreSQL الحقيقي والـAPI الحقيقي.
- ممنوع Mock Data.
- استعمل نفس حسابات الموظفين الحالية، لكن بواجهة Doctor Portal مخصصة.
- كل طبيب يرى فقط المرضى والبيانات المسموح بها حسب:
  - Site
  - Department
  - Service
  - Assignment
  - Encounter
  - Appointment
  - Admission
- دعم كامل:
  - Français
  - العربية RTL
  - English
- Responsive كامل على:
  - iPhone
  - Android
  - Tablet
  - Desktop
  - PWA standalone
- TypeScript = 0 errors.
- Runtime SQL = 0 errors.
- 0 White Screens.
- جميع العمليات الطبية تسجل في Audit وTimeline.
- لا تبدأ Nurse Station أو أي Module آخر قبل إكمال Portail Médecin.

==================================================
23. Data Scope
==================================================

طبق Scope صارم:

الطبيب يرى Patient فقط إذا:

- عنده Appointment معه.
- هو doctorId للConsultation.
- هو attending physician للAdmission.
- هو Assigned في Emergency.
- عضو في Care Team.
- عنده Permission واسعة مثل medical_director.

اختبر IDOR:

Doctor A يحاول فتح Patient تابع لـDoctor B بدون علاقة.
→ 403 أو 404.
→ لا Data Leak.
