نريد الآن إنهاء Module Urgences بطريقة صحيحة ومترابطة.

مهم جدًا:
- لا تغيّر Dashboard الحالية.
- لا تغيّر الألوان أو الـLayout أو الـSidebar أو الـTopbar.
- لا تضف Widgets جديدة إلى Dashboard.
- ركّز فقط على صفحة ملف مريض الاستعجالات:
  /emergencies/:id
- استعمل نفس Design System الحالي.
- استعمل Mock Data حاليًا، لكن جهّز كل شيء للربط لاحقًا مع Backend وPostgreSQL.
- دعم كامل للفرنسية والعربية RTL والإنجليزية.
- تطبيق Permissions وAudit على جميع العمليات.

==================================================
1. فتح ملف مريض الاستعجالات
==================================================

عند الضغط على:
- Ouvrir
- Prendre en charge

يجب فتح الصفحة:
 /emergencies/:id

بدون Refresh كامل للصفحة.

يجب تمرير نفس:
- Patient ID
- MPI
- Emergency ID
- Triage level
- Arrival time
- Assigned doctor
- Assigned nurse
- Room
- Current status

ممنوع إعادة إدخال بيانات المريض.

13. الربط مع بقية Modules
==================================================

عند اختيار Hospitalisation:
- أنشئ Admission Mock جديدة تلقائيًا.
- اربطها بنفس Patient ID وEmergency ID.
- حدّث Dashboard Admissions.
- لا تطلب إعادة إدخال بيانات المريض.

عند اختيار Bloc opératoire:
- أنشئ Surgical Request Mock.
- اربطها بالطوارئ والمريض.

عند اختيار Réanimation:
- أنشئ ICU Request Mock.

عند اختيار Transfert:
- أنشئ Transfer Record Mock.

عند اختيار Retour domicile:
- أغلق الزيارة وحدث حالة المريض في Dashboard.

17. معايير القبول
==================================================

لا تعتبر المهمة مكتملة إلا إذا:

- زر Ouvrir وPrendre en charge يفتحان نفس الملف.
- جميع بيانات المريض تنتقل بدون إعادة إدخال.
- الحالة تتغير وتحدث Dashboard.
- Timer يعمل.
- Timeline تعمل.
- العلامات الحيوية تعمل.
- Scores تتحسب.
- ABCDE يعمل.
- التحاليل والأشعة تعمل بـMock Data.
- الأدوية والإجراءات تعمل.
- الملاحظات تعمل.
- Observation تعمل.
- القرار النهائي يعمل.
- Hospitalisation / Bloc / Réanimation / Transfert تنشئ سجلات مرتبطة.
- Audit يعمل.
- Permissions مطبقة.
- اللغات الثلاث تعمل.
- RTL صحيح.
- لا يتم كسر أي Module موجود.

بعد الانتهاء اعرض:

1. Structure الملفات الجديدة.
2. Components التي أنشأتها.
3. Permissions المستعملة.
4. العلاقات بين Urgences وPatients وAdmissions وHospitalisation وBloc.
5. ما تم تأجيله للـBackend.
6. قائمة اختبارات يدوية كاملة.
