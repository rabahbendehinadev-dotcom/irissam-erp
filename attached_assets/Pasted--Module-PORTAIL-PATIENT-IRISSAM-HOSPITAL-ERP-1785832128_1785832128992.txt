PORTAIL PATIENT — بوابة المريض

داخل نظام IRISSAM HOSPITAL ERP.

مهم جدًا:

- لا تغيّر تصميم النظام الإداري الحالي.
- أنشئ تجربة منفصلة ومبسطة للمريض.
- استعمل PostgreSQL الحقيقي والـAPI الحقيقي.
- ممنوع Mock Data.
- دعم كامل:
  - Français
  - العربية RTL
  - English
- Responsive كامل على:
  - iPhone
  - Android
  - Tablet
  - Desktop
  - PWA standalone
- TypeScript = 0 errors.
- Runtime SQL = 0 errors.
- 0 White Screens.
- جميع البيانات الطبية المعروضة يجب أن تمر عبر صلاحيات واضحة وموافقة المستشفى.

==================================================
3. تفعيل الحساب
==================================================

طرق التفعيل:

- من طرف الاستقبال.
- رابط Activation.
- OTP عبر SMS أو Email.
- كود مؤقت يطبعه المستشفى.
- إعادة تعيين كلمة المرور.

القواعد:

- لا يستطيع المريض إنشاء حساب لشخص آخر.
- التحقق من:
  - MRN
  - تاريخ الميلاد
  - رقم الهاتف أو البريد
- OTP تنتهي صلاحيته.
- منع Brute Force.
- تسجيل كل المحاولات.

==================================================
21. Backend Data Scope
==================================================

كل Endpoint في Patient Portal يجب أن يتحقق أن:

token.patientId === requestedPatientId

ممنوع الاعتماد على ID من الـFrontend فقط.

اختبر IDOR:

- Patient A يحاول فتح Patient B.
- النتيجة 403 أو 404.
- لا Data Leak.
