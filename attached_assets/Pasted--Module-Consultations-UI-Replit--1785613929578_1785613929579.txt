تمام، نروحو الآن لـ **Module Consultations**، بصح نخدموه وحدو وبنفس الـUI الحالي، وما نخليوش Replit يبني المختبر ولا الأشعة ولا الصيدلية كاملين؛ غير يجهز الربط معهم كطلبات.

انسخ له هذا البرومبت:

```text
الآن ابدأ تطوير Module جديد فقط داخل نظام IRISSAM HOSPITAL ERP:

MODULE: CONSULTATIONS MÉDICALES

مهم جدًا:

- لا تغيّر الـDashboard.
- لا تغيّر الـSidebar أو الـTopbar أو الهوية البصرية.
- استعمل نفس الـFoundation ونفس الـDesign System الحالي.
- اربط Module الاستشارات مع المرضى والمواعيد والقبول الموجودة حاليًا.
- لا تبنِ الآن Module المختبر أو الأشعة أو الصيدلية بالكامل.
- حضّر فقط طلبات التحاليل والأشعة والوصفات كبيانات Mock قابلة للربط لاحقًا.
- استعمل Mock Data فقط حاليًا.
- دعم كامل للغات:
  - Français افتراضيًا
  - العربية مع RTL
  - English
- لا تكتب نصوصًا ثابتة خارج نظام الترجمة.
- طبّق الصلاحيات والـAudit Trail في جميع العمليات الحساسة.

==================================================
1. هدف Module
==================================================

إنشاء Module احترافي يسمح للطبيب بإدارة الاستشارة الطبية كاملة من بداية استقبال المريض إلى إنهاء الاستشارة.

يجب أن تكون الاستشارة مرتبطة دائمًا بـ:

- Patient MPI
- Médecin
- Service
- Site
- Rendez-vous اختياري
- Admission اختياري
- Date et heure
- Type de consultation

أنواع الاستشارة:

- Consultation programmée
- Consultation sans rendez-vous
- Consultation de contrôle
- Consultation spécialisée
- Consultation ambulatoire
- Téléconsultation كـPlaceholder فقط
- Consultation issue des urgences
- Consultation liée à une hospitalisation

==================================================

==================================================
15. Terminer la consultation
==================================================

عند الضغط على Terminer:

نفذ Validation نهائية:

- Motif موجود.
- Diagnostic موجود أو سبب عدم التشخيص.
- Compte rendu موجود.
- الطبيب محدد.
- لا توجد Prescription ناقصة.
- الطلبات محفوظة.

اعرض Modal Résumé فيها:

- Patient
- Diagnostic
- Prescriptions
- Analyses demandées
- Imagerie demandée
- Documents
- Prochain rendez-vous
- Orientation

أزرار:

- Retour et modifier
- Terminer et imprimer
- Terminer sans impression

بعد الإنهاء:

- يصبح Status = Terminée.
- تصبح البيانات الطبية Read-only.
- التعديل بعد الإنهاء يحتاج Permission خاصة.
- أي تعديل لاحق ينشئ Version جديدة ولا يمسح النسخة القديمة.
- سجّل العملية في Audit Trail.

17. ربط Patient Profile
==================================================

- لا تنفذ Hospitalisation كاملة الآن.

==================================================
25. معايير القبول
==================================================

لا تعتبر Module مكتملًا إلا إذا:

- قائمة الاستشارات تعمل.
- الفلاتر والبحث يعملان.
- إنشاء استشارة يعمل.
- اختيار المريض يعمل.
- العلامات الحيوية تعمل.
- التشخيص يعمل.
- Prescription Builder يعمل ببيانات Mock.
- طلب التحاليل يعمل.
- طلب الأشعة يعمل.
- الشهادات تعمل.
- إنهاء الاستشارة يعمل.
- صفحة التفاصيل تعمل.
- الطباعة تعمل بصريًا.
- Patient Profile يتحدث.
- الموعد يتغير Status بصريًا.
- Permissions مطبقة.
- Audit hooks مستدعاة.
- Versioning ظاهر.
- اللغات الثلاث تعمل.
- RTL صحيح.
- لا توجد أخطاء Console.
- لا يتم كسر Modules الحالية.
- لا يتم بناء أي Module آخر.

بعد الانتهاء اعرض:

1. Structure الملفات الجديدة.
2. Components التي تم إنشاؤها.
3. Permissions المستعملة.
4. العلاقات مع Patients وRendez-vous وAdmissions.
5. ما تم تأجيله للـBackend.
6. قائمة اختبارات يدوية كاملة.
```

كي يكمل، ما ننتقلوش مباشرة لـUrgences؛ نراجع أولًا هل الاستشارة تقدر تبدأ من المريض ومن الموعد، وهل الإنهاء والوصفة وطلبات التحليل يخدموا بلا أخطاء.
