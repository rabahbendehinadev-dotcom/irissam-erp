Task #124 — Medical Stock Management (Enterprise Grade)

Objectif :
Construire un module complet de Gestion du Stock Médical (Medical Inventory) pour un ERP Hospitalier de niveau Enterprise.

IMPORTANT :
- Ne jamais utiliser de Mock Data.
- Toutes les données doivent provenir de PostgreSQL.
- TypeScript : 0 erreur.
- Responsive Desktop / Tablet / Mobile.
- Compatible PWA.
- Respecter l'architecture actuelle du projet.
- Utiliser React + Node.js + PostgreSQL.
- Toutes les opérations critiques doivent être transactionnelles.
- Audit log sur chaque action sensible.
- RBAC complet avec permissions.
