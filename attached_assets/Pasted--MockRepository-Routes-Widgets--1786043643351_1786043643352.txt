## 3. اختبار الأخطاء والحالات الخاصة

تحقق من:

* 401 → إعادة توجيه صحيحة إلى Login.
* 403 → Accès refusé.
* 404 → Page introuvable.
* API 500 → Error State مع Retry.
* API يرجع قائمة فارغة → Empty State.
* Network interruption → لا يحدث White Screen.
* Refresh مباشر على Route داخلية → الصفحة تعمل.
* Session منتهية → تعامل صحيح بدون Loop.
* Permission ناقصة → لا يظهر محتوى غير مصرح به.
