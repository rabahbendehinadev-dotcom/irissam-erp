نفّذ Task #106 كاملة في Build mode الآن.

الهدف:
منع أي White Screen نهائيًا، وتثبيت كل صفحات الـFrontend بعد الانتقال من Mock Data إلى PostgreSQL API.

مهم جدًا:
- لا تغيّر التصميم الحالي.
- لا تغيّر الـUX إلا لإضافة Loading / Empty / Error states.
- لا تضف Features جديدة.
- لا تبدأ Facturation أو أي Module جديد.
- أصلح فقط الاستقرار، الـguards، الـmappers، والـError Boundaries.

==================================================
1. PageErrorBoundary مشترك
==================================================

أنشئ Component مشترك:

src/components/shared/PageErrorBoundary.tsx

المطلوب:
- يلتقط أي Runtime Error داخل الصفحة.
- يعرض:
  "Une erreur est survenue lors du chargement de cette page."
- زر Réessayer.
- زر Retour au tableau de bord.
- يسجل:
  route
  error name
  error message
  component stack
- بدون تسجيل بيانات طبية حساسة أو Tokens.

استعمله حول جميع الصفحات الرئيسية.

==================================================
2. إصلاح Dashboard
==================================================

أصلح الـ4 imports/exports المكسورة:

- useGetAlerts
- useGetAdmissionsChart
- useGetConsultationsChart
- useGetServicesChart

راجع package أو generated api-client-react وتأكد أن:
- الأسماء صحيحة.
- الـhooks موجودة فعلًا.
- أو استبدلها بالـhooks الصحيحة الموجودة.
- لا تترك أي import غير موجود.
- Dashboard يفتح حتى لو فشل Widget واحد.

لف كل Widget حساس بـWidget-level fallback حتى لا يطيح Dashboard كامل.

- Patients

- .find

على قيمة غير مؤكدة.
