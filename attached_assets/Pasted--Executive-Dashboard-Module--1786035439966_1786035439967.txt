لا تبدأ أي Module جديد.

الآن قبل مواصلة تدقيق الصفحات واحدة بواحدة، قم بعمل Audit شامل داخل كامل المشروع على طريقة استعمال `apiClient`.

المشكلة التي تم اكتشافها:

`apiClient.get()` و`apiClient.post()` و`apiClient.put()` و`apiClient.patch()` و`apiClient.delete()` ترجع البيانات مباشرة، وليست داخل `response.data`.

ابحث داخل كامل Frontend عن جميع الحالات المشابهة لـ:

```ts
apiClient.get(...).then((r) => r.data)
apiClient.get(...).then((r) => setData(r.data))
const response = await apiClient.get(...)
response.data
result.data
res.data
```

راجع أيضًا:

* Hooks
* Services

لكل نتيجة:

1. تحقق أولًا من النوع الحقيقي للقيمة التي ترجعها `apiClient`.
2. لا تحذف `.data` بشكل أعمى إذا كان الكود يتعامل مع Axios مباشر أو API مختلفة.
3. صحح فقط الحالات التي تستعمل `apiClient` الخاص بالمشروع والذي يرجع البيانات مباشرة.
4. لا تغير شكل الـAPI ولا تعدل Backend بدون ضرورة.
5. لا تنشئ Wrapper جديدًا ولا تكرر الـAPI client.
6. لا تعيد كتابة أي Component يعمل.

بعد ذلك اختبر الصفحات المتأثرة وتأكد من:

* البيانات الحقيقية تظهر.
* البيانات الفارغة تعرض Empty State.
* أخطاء API تعرض Error State مع Retry.
* لا يوجد `return null` يؤدي إلى White Screen.
* لا توجد أخطاء Runtime.
* لا توجد أخطاء Console.
* لا توجد أخطاء TypeScript.
