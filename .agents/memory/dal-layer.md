## ActorCtx shape (types.ts)
```typescript
interface ActorCtx {
  userId:   string;
  userName: string;   // NOT `name` or `role`
  userRole: string;   // NOT `role`
  siteId?:  string;
}
```
Route helper pattern:
```typescript
function actor(req: AuthenticatedRequest): ActorCtx {
  return { userId: req.auth?.userId ?? "system", userName: req.auth?.userId ?? "system", userRole: req.auth?.role ?? "guest" };
}
```

## Critical column name mappings (checked against actual schema)

### admissionsTable
- `type` (not `admissionType`)
- `motif` (not `chiefComplaint`) — **not null**
- `serviceName` / `doctorName` — **not null**
- `admissionDate` (date string YYYY-MM-DD) + `admissionTime` (HH:MM text)
- `actualDischargeDate` + `actualDischargeTime`
- `dischargeNotes`
- `admissionNumber` — generated by AdmissionService as `ADM-YYYY-NNNNN`
- `patientMpiId` (not `patientMrn`)
- "Currently hospitalized" = `eq(admissionsTable.status, "active")` (not `isNull(dischargedAt)`)
- "Admissions today" = `eq(admissionsTable.admissionDate, todayDateString())` (date string comparison)

### occupancyBedsTable
- Status enum: `disponible | occupe | reserve | nettoyage | hors_service | maintenance`
- **"libre" does NOT exist — use "disponible"**

### labOrdersTable
- `test` (not `testName`)
- `urgency` (not `priority`)
- `requestedAt` (not `orderedAt`)

### imagingOrdersTable
- `exam` (not `examName`)
- `region` — not null

### prescriptionsTable
- Status: `prescrit | prepare | delivre | annule` — **"dispensée" does NOT exist**
- `dispensedById` (not `dispensedBy`)

### medicationsTable
- `quantity` (not `stock`)
- `lowStockThreshold` (not `reorderLevel`)

### alertsTable
- No `isActive` column → use `isNull(deletedAt)`
- No `detail` / `description` / `category` / `patientId` columns
  → use `message`, `module`, `entityId`

### appointmentsTable
- `departmentName` (not `service`)
- No `patientFirstName` / `patientLastName` — use `patientName`

### patientsTable
- No `name` / `age` / `service` / `registeredAt` / `medicalJson` / `emergencyContactJson` / `insuranceJson`
- Medical data: `allergies[]`, `chronicDiseases[]`, `majorHistory[]` arrays
- Emergency contact: `emergencyContactName/Relation/Phone/Address` separate columns
- Insurance: `insuranceType/OrgName/MemberNumber/ValidUntil` separate columns
- `createdAt` replaces `registeredAt`

### consultationsTable
- No `date` column — use `scheduledAt` (timestamp)

### operatingRoomsTable
- Status enum: `libre | reserve | en_preparation | en_intervention | nettoyage | hors_service | maintenance`
- **NOT "available" / "occupied" / "prep"**

### bloodBankTable
- `unitsAvailable` + `unitsReserved` (not `totalBags` / `availableBags`)
- No `urgentRequests` / `expiringSoon` columns

### dailyStatsTable
- `statDate` (not `date`)
- `newAdmissions` (not `admissions`)
- `discharges` (not `sorties`)
- No `rendezVous` / `analyses` / `imaging` / `invoices` / `revenueDA`
